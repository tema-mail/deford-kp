# deford-kp

Коммерческие предложения студии Deford, по папке на клиента. Статичные страницы, GitHub Pages через workflow, закрыты от индексации.

- `elite-rose/` – интернет-магазин для Elite Rose (Новосибирск), 19.10.2026.
- `loveberry/` – интернет-магазин для LOVEBERRY (Тольятти) от Target Factory, спецпредложение «Базовый» 50 000 ₽ до 31.10.2026.

Исходники разборов (транскрипты, кадры) – `~/Documents/КП-Дефорд/`.
- `sikor/` – интернет-магазин для SIKOR (мужская одежда, Челябинск), стиль варианта Kavara, цветные фото. Тарифы – черновые до видео.
